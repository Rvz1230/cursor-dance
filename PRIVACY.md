# Privacy Policy

**Last updated:** June 1, 2026

## Data Collection

CursorDance does **not** collect, store, or transmit any personal data, browsing history, or user activity.

All extension configuration data (themes, settings, site rules) is stored locally on the user's device using the `chrome.storage.local` API and never leaves the browser.

## Optional AI Feature

The optional AI Scheme Assistant sends the current theme configuration context to a user-designated API endpoint when the user explicitly triggers it. This endpoint is configurable by the user and defaults to none. No data is sent automatically or without user action.

## Third-Party Services

This extension does not integrate any third-party analytics, tracking, or advertising services.

## Data Sharing

We do not sell, transfer, or share any user data with third parties.

## Changes

Any changes to this policy will be reflected in this document with an updated date.
