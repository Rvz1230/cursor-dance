深色模式：先加一层语义令牌

现在全站直接写死 bg-white / text-slate-900，无法整体切换。先定义语义层，再机械替换。整页右上角的开关就走这一层。

语义名 浅色 深色 用途
surfacewhiteslate-900卡片 / 面板底
surface-sunkenslate-50slate-950页面底 / 次级面板
hairlineslate-200slate-7001px 描边
ink / ink-2 / ink-3 / ink-4900 / 600 / 500 / 400100 / 300 / 400 / 500标题 / 标签 / 描述 / 辅助

功能色（emerald / rose / amber / teal / sky）在深色下换成 -400 字色 + -950 底色，保持对比度。这一步做完，其余页面是机械替换。
