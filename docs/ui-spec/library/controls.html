二维、角度、曲线

这三类现在都被拆成两个滑块或六个词，是最该换掉的。

偏移 X 50% · Y 42%

替掉「水平偏移 / 垂直偏移」两个滑块——而且那两个滑块的含义还会随入场边翻转。

发射角度 45°

拖动转盘或点预设。按住 Shift 以 15° 吸附。

自定义缓动 cubic-bezier(0.34, 1.56, 0.64, 1)

曲线超出顶部虚线即为过冲。这正是键盘动效那个 bug 的成因——过冲曲线被当成整条动画的 timing function，进度冲过 1 后钳在最后一帧。画出来就一眼看见。
