提交时机是 change（失焦或 Enter），不是每次按键——每键都 clamp 的话，min=0、max=500 时想输「50」会先被夹一次。空串与非数字视为放弃编辑、保持原值；Esc 放弃草稿。

二维、角度、曲线

这三类现在都被拆成两个滑块或六个词，是最该换掉的。三个都能只用键盘操作。

偏移 X 50% · Y 42%

替掉「水平偏移 / 垂直偏移」两个滑块——而且那两个滑块的含义还会随入场边翻转。底边与左边那两条轨是 X / Y 两个分量，可聚焦、可用方向键调。

发射角度 45°

拖转盘或点预设。拖拽时按住 ⇧ 以 15° 吸附；聚焦转柄后 ←→ ±1°、⇧ ±15°。

自定义缓动 cubic-bezier(0.34, 1.56, 0.64, 1)

曲线超出 1.0 那根虚线即为过冲，过冲量由 pts 算出来、不手写。 这正是键盘动效那个 bug 的成因——过冲曲线被当成整条动画的 timing function，进度冲过 1 后钳在最后一帧。画出来就一眼看见。 两个控制点各是一个 role="slider"：←→ 调 x、↑↓ 调 y、⇧ 十倍步长。

实现时要保住的不变量：可见范围 == 钳位范围 （[-0.6, 1.6]）。两者由同一对常量导出， 改一个必须改另一个——只改钳位的那一版会让「弹跳」的第一个控制点落到盒子外面。 160px 的高度是从这条不变量反推的：0–1 那一段还得占到足够高才读得出形状。

开关、单选卡、复选

三种都由共享层就地接管已有标记：aria-checked 是真值，视觉类只是它的投影。

带说明的开关

旋钮上的 .switch-on 不写在标记里，由 aria-checked 投影出来。方向不能反：先 toggle 类再从类推 aria 就是两份真值。

单选卡（带图标与描述）

清空逻辑收在**最近的** role="radiogroup" 里，不是全站 querySelectorAll——后者在「页面上恰好只有一组」时看不出问题，第二组一出现两组就互相清空。

复选（半选由子项推导）

五条子项就是桌面端的五个动作。父项的 aria-checked="mixed" 和「3 / 5 已选」都是**算出来的**：勾掉一条就跟着变。半选状态下点父项是**全选**——半选 → 全不选会让人以为自己撤销了什么，而他刚才什么都没勾。
