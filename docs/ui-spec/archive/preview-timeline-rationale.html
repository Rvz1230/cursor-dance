舞台改了什么

拆掉三层假家具

原来舞台里套着一个内嵌画框（inset-x-8 top-20）、一条假搁板、一个中心的假光标脉冲环。效果被裹在三层装饰里，还挤在一个更小的内框里。现在舞台就是效果区。

效果在你点的位置发生

原来指针位置有采集但效果恒定在正中，所以看不出「点哪触发哪」。

慢放 / 逐帧 / A-B 对比

调动效必需的三件事，原来一个都没有——只有重播和循环间隔。

底色可切 + 运动轨迹

原来底色写死近白，浅色粒子看不清；轨迹（洋葱皮）让运动路径一次看全。

两处装饰渐变 + 一个野生紫

舞台底和内框各有一条 linear-gradient（DESIGN.md 禁止），长按进度环写死 #7C3AED 紫色（不在色板里）。都已去掉。

时间轴改了什么

现有实现的拖拽、吸附、键盘、ghost 预览都保留。

播放头可拖，驱动舞台

原来是一次性 CSS transition 从 0 跑到宽度，不能拖、不能停，头上的标签还恒显总时长。现在它是唯一时间源。

色块内嵌缓动曲线

时长可编辑，但「运动的形状」原来在任何地方都看不见。

独奏 / 静音

四条效果叠在一起时，想单独看粒子只能去关掉另外三张卡。

缩放 + 吸附档位

原来总长由最长轨道决定且不可缩放，120ms 的音效在 900ms 里只有一条缝；吸附写死 20ms。

去掉六色渐变色块

原来每条轨道一个 bg-gradient-to-b 加六种色调（含 violet）。现在色块是白底描边，色调只保留标签前的小圆点。
