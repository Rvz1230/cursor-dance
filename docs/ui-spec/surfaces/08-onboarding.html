C 欢迎使用 CursorDance

先授权，它才能看到你的鼠标

CursorDance 需要「辅助功能」权限来接收全局的鼠标和键盘事件。它不读取内容，只知道你在哪按了哪个键。

不授权也能用：工作台里的预览、光标皮肤的校准、键盘动效的屏幕预览全部可用，只是效果不会出现在桌面上。
