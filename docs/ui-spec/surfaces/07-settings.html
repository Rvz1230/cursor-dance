尺寸换算

两块屏缩放不同时，48px 的光标在 2× 屏上物理尺寸只有 1× 屏的一半。「跟随各屏缩放」保证物理大小一致，「按主屏统一」保证像素值一致。

开启后效果能跟着「你敲到的是什么」变化，相关的光标状态会整组点亮。每项都有代价，写在下面。

开了也可能取不到

覆盖率必然是部分的：终端、部分 Java 应用、未开辅助功能的 Electron 应用不向系统暴露元素级信息。 这种时候效果会回落到指针位置——不是没生效，是锚点换了。 哪一次回落了，在诊断面板的「内容信号」那一格能查到。
