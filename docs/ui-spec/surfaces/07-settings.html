显示与多屏

走查时发现整套稿子从没考虑多屏：键盘动效的屏幕预览、光标皮肤的准星测试、应用规则的点选，都默认只有一块屏。这里是它的归属。

效果出现在
主屏 · 2×
副屏 · 1×

尺寸换算

两块屏缩放不同时，48px 的光标在 2× 屏上物理尺寸只有 1× 屏的一半。「跟随各屏缩放」保证物理大小一致，「按主屏统一」保证像素值一致。
