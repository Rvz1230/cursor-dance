# 主题库手动验证清单

更新日期：2026-08-06

使用本清单在本地工作台 `http://localhost:5173/` 中验证新的主题库流程。

## 测试数据

不依赖仓库外的固定样例。流程 B 会从当前版本导出一份 schema v4 主题 JSON，流程 C 再导入同一文件，从而同时验证导出与导入契约。

## 流程 A：新建主题

1. 打开主题库侧栏，点击「新建」。
2. 在弹窗中，保持「起始模板」为「空白主题」，输入：
   - 主题名称：`Studio Verify A`
   - 描述：`手动验证主题`
3. 点击「创建主题」。

预期结果：

- 弹窗关闭。
- 左侧列表出现名为 `Studio Verify A` 的新主题卡片。
- 新主题自动被选中。
- 工作台保持可编辑状态，不崩溃。

## 流程 B：从已有主题创建

1. 再次点击「新建」。
2. 将「起始模板」设为任意已有主题，例如「木鱼方案」。
3. 命名为 `Woodfish Clone Check`。
4. 点击「创建主题」。
5. 切换到 `doubleClick`，将触发时机设为「第二次抬起后」、波纹样式设为「柔和面波」、粒子形态设为「火花」。
6. 保存后，从主题菜单导出当前主题，并保留下载的 JSON 文件供流程 C 使用。

预期结果：

- 新主题出现在列表中并被选中。
- 核心动作设置从基础主题复制，而非重置为空默认值。
- 在克隆主题上修改设置后切换回去，不会影响原始主题卡片。

## 流程 C：导入主题 JSON

1. 点击「导入」。
2. 选择流程 B 导出的 schema v4 主题 JSON。

预期结果：

- 导入的主题以导出时的名称出现在列表中，并使用新的唯一主题 id。
- 导入的主题自动被选中。
- `doubleClick` 的触发时机、波纹和粒子配置与导出前一致。
- 预览轨道更新时不抛出 UI 错误。

## 流程 D：保存并刷新

1. 创建或导入主题后，点击顶部的「保存」。
2. 刷新页面。

预期结果：

- 新建/导入的主题在刷新后仍然存在。
- 选中的主题在列表中仍然可用。
- 在内置主题和自定义/导入主题之间切换仍然正常。

## 流程 E：触发器配置持久化

在导入的主题上：

1. 切换到 `doubleClick`。
2. 确认「触发时机」为「第二次抬起后」。
3. 确认「波纹样式」为「柔和面波」。
4. 确认「粒子形态」为「火花」。
5. 点击「保存」，然后刷新。

预期结果：

- 刷新后相同的值仍然保持选中。
- 预览渲染时没有布局错误或控制台错误。

## 流程 F：无效导入防护

1. 创建一个包含无效 JSON 的临时文件，例如：

```json
{ "themePack": }
```

2. 通过弹窗导入。

预期结果：

- 弹窗保持打开。
- 导入面板中显示可读的错误信息。
- 已有主题不被移除或替换。

## 可选的运行时检查

如果在 Chrome 中作为真实扩展选项页加载：

1. 选择流程 C 导入的主题。
2. 点击「保存」。
3. 在普通 `http/https` 页面上触发 `leftClick`、`doubleClick`、`wheel` 和 `hover`。

预期结果：

- `leftClick` 显示文字 + 波纹 + 粒子。
- `doubleClick` 使用更强的组合反馈。
- `wheel` 在样本主题中仅响应向下滚动。
- `hover` 仅在按钮/链接上经过短暂延迟后触发。
